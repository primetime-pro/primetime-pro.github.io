# Цель

Опубликовать PrimeTime Pro как независимую бесплатную PWA на `https://primetime-pro.github.io/`, не изменяя клиентский PrimeTime и данные backend.

# Сделано

- Подготовлен отдельный статический пакет кабинета из опубликованной версии v824.
- Главный вход перенесён в корень сайта; клиентские ссылки оставлены на действующем PrimeTime.
- Созданы независимые manifest, service worker cache `primetime-pro-v1` и Pages workflow.

# Проверено

- Исходная v824 опубликована и визуально проверена на 390, 760 и 1440 px.
- Локальная проверка отдельного пакета выполняется через `node verify-site.mjs`.

# Текущий этап

Форма бесплатной GitHub organization `primetime-pro` подготовлена. GitHub требует контактный email владельца перед созданием.

# Следующие шаги

1. Создать публичный organization Pages repository.
2. Опубликовать пакет и проверить live URL/PWA на 390, 760 и 1440 px.
3. Подтвердить auth redirect allowlist для нового origin.
4. Только затем подготовить обратимый переход со старого provider URL.

# Зафиксированные решения

- Бесплатный GitHub Pages; без домена и платных функций.
- Старый Pro не удаляется.
- Старый клиентский PrimeTime не переносится и не переименовывается.

# Ограничения и блокеры

- Нельзя передавать GitHub контактный email владельца без его прямого ввода или подтверждения конкретного адреса.
- Новый auth origin должен быть разрешён в Supabase до окончательного переключения.
